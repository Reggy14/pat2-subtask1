## 1. Overview of Morse Code
Morse code is a method of transmitting text information as a series of on-off tones, lights, or clicks. Each character (letter, numeral, or punctuation mark) is represented by a unique sequence of short and long signals, commonly referred to as *dots* and *dashes*. Because it relies on simple binary signaling (signal present vs. signal absent), it can easily be transmitted over primitive electrical wires, radio waves, or even visual flashes of light.

## 2. Historical Context
* *The Inventors:* Morse code was developed in the late 1830s and early 1840s by *Samuel F. B. Morse* and his assistant *Alfred Vail*. 
* *The Problem:* Before the electrical telegraph, long-distance communication relied on visual systems like semaphores, which required a clear line of sight and failed in poor weather or at night. 
* *The Breakthrough:* Morse and Vail invented an electrical telegraph system that sent pulses of electrical current along wires to control an electromagnet at the receiving end. They needed a standardized linguistic code to translate those electrical pulses into readable human language.
* *Refinement:* The original American Morse code was later refined by Friedrich Gerke in 1848 to create what became the *International Morse Code*, standardizing the system for global maritime and aviation use.

## 3. How the Morse Code System Works
The system operates on strict timing rules based on a fundamental unit of time known as a *dot duration*. 

### The Elements
* *Dot (•):* The basic unit of time (1 unit long).
* *Dash (—):* Equivalent to three dots in length (3 units long).

### Timing and Spacing Rules
* *Element Spacing:* The gap between the dots and dashes within a single character is equal to *1 dot duration*.
* *Character Spacing:* The gap between individual letters in a word is equal to *3 dot durations*.
* *Word Spacing:* The gap between entire words is equal to *7 dot durations*.
